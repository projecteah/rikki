# Rikki

A simple notes app.

## Features

- Quick capture of thoughts
- Markdown rendering
- Tags (#tag)
- Public / Private notes
- Dark mode
- Multi-language (en, sc, tc, lzh)
- Sync with Koa API + MongoDB
