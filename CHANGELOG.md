# Changelog

## [0.3.0] - 2022-12-23
> "Wengang" (文港; 'port of words') is a town in Kiangsi, China, known for making ink brushes.

### Added
- Public notes page and visibility toggle
- MongoDB storage with sync API
- Multi-language support
- Tag filtering

### Changed
- Migrated to Nuxt 3
- Restructured as pnpm monorepo

## [0.2.0] - 2022-11-08
> "Tam-sin" (淡新; 'clear and new') is a county archive of old northern Taiwan.

### Added
- Markdown notes
- Delete support
- Dark mode
